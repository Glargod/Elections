# TrustVote 3000: Rebuilding Democracy

TrustVote 3000 is a secure, transparent, policy-driven voting system. Key features include:
- **Voter Readiness Certificate**: Ensures civic literacy.
- **Dynamic PolicyMatch**: Recommends a ranked policy alignment (party + score + PlatformEval summary + valence packet). The voter then sees the person attached to that alignment and confirms, switches, or adds valence questions. Only the confirmed choice becomes the ballot (see [flowchart](flowchart.png)).
